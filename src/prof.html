Comment jouer le MJ ?

Le MJ joue depuis son propre téléphone, pas depuis cet écran : cliquez sur « Afficher le code MJ » (il se masque seul au bout de 10 s) et suivez la consigne.

Je n’ai qu’un seul appareil

Le MJ répond en secret : si vous jouez sur l’écran projeté, tout le monde voit vos réponses. Trois solutions :

  1. Écran étendu : faites glisser une fenêtre « joueur » sur l’écran non projeté.
  2. Masquer l’écran (bouton en haut à droite) : plus rien n’est projeté le temps de répondre ; les aventuriers continuent sur leurs téléphones. Réaffichez pour la correction.
  3. Plus simple : passez en Duel de guildes à deux guildes ennemies. Vous (MJ) rejoignez la guilde 1 avec votre téléphone, tous les autres rejoignent la guilde 2.

    Aide rapide

    1. Choisir : le mode de jeu et les réglages (types de questions, difficulté, temps de lecture, points), puis les thèmes à jouer, rangés par royaume. Cochez un thème, un royaume entier, ou tentez « Surprends-moi ».
    2. Vérifier : les questions sont tirées au sort parmi les thèmes cochés. Une question déjà jouée avec ce navigateur ne revient qu’une fois toutes les autres épuisées. Vous pouvez remplacer, retirer ou réordonner (réponses masquées tant que vous ne cochez pas « Afficher les réponses »).
    3. Ouvrir le donjon : les aventuriers vont sur la page joueur (QR code ou adresse), tapent le code et leur pseudo (30 maximum).
    4. Duel de guildes : chaque aventurier glisse son jeton dans une guilde ; vous pouvez renommer les guildes et déplacer les joueurs.
    5. Aventuriers VS MJ : « Afficher le code MJ » donne le code à taper sur votre téléphone pour jouer contre le groupe.
    6. Jouer : les règles s’affichent, puis les questions. « Joueurs » permet de renommer, d’exclure ou de faire entrer un retardataire (QR code). « +30 s » rallonge, « Écourter » passe directement aux gagnants.

    Plusieurs donjons peuvent être ouverts en même temps sur des ordinateurs différents : chaque donjon a son propre code.

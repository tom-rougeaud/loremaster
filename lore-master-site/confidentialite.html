Confidentialité

En bref : pas de compte, pas de nom de famille, pas d’adresse e-mail, pas de publicité, pas de cookie, pas de mesure d’audience. Les joueurs choisissent leur nom d’aventurier (un surnom suffit). Les données de jeu sont effacées automatiquement.

Aucun nom de famille, aucune adresse e-mail, aucune photo et aucune adresse IP ne sont enregistrés dans les tables de Lore Master.

  • Un surnom suffit (jamais de nom de famille). Un surnom tiré au sort est proposé pour rester discret. Le MJ peut renommer ou retirer un nom inapproprié.
  • Les noms grossiers les plus courants sont refusés automatiquement.
  • Si un élève quitte la page du jeu pendant une partie (autre onglet, autre application), le MJ en est averti. L’application ne sait pas quelle page a été ouverte et n’enregistre rien.
  • La fiche garde aussi, sur l’appareil seulement, les derniers résultats par thème pour proposer « À revoir ». Rien de cela n’est envoyé au MJ ni à la base.
  • L’export de la fiche est un fichier que le joueur garde et protège lui-même.

  • Hébergement des pages : GitHub Pages. Comme tout hébergeur, GitHub peut conserver des journaux techniques de connexion (adresse IP) ; voir la politique de confidentialité de GitHub.
  • Base de données et temps réel : Supabase, dans le projet créé par l’auteur de l’outil (région Union européenne recommandée). Seules les données du tableau ci-dessus y sont enregistrées ; comme tout hébergeur, Supabase garde aussi des journaux techniques de connexion pendant une courte durée.
  • Aucun autre service : polices, images et bibliothèques sont intégrées aux pages. Aucun traceur, aucun compteur de visites.

La personne qui met Lore Master en ligne et l’utilise avec un groupe (classe, club, association) est responsable de cet usage. Il est conseillé d’en informer les participants et, en milieu scolaire, si besoin, le délégué à la protection des données (DPO) de l’établissement ou de l’académie.

Pour toute question ou demande d’effacement anticipé, adressez-vous à votre MJ. Pour une question sur l’outil lui-même, utilisez la page Contact.
